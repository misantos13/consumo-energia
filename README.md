Projeto desenvolvido para atividade de **Desenvolvimento de Sistemas**. Tendo a proposta de calcular de forma estimada o consumo em watts e custo mensais de energia elétrica de um aparelho informado pelo usuário.

---

# Objetivo do Programa 📝

Esse projeto tem como objetivo calcular e informar o consumo de energia de um **Aparelho Eletrônico** usando informações como a **Potência em Watts** e o **Tempo Médio de Uso Diário**. Assim como o cálculo de **Custo Estimado**, tendo como valor fixo R$ 0,93 kWh.


**Objetivo da atividade:**
* Publicação do código-fonte através do Git e GitHub
* Prática da Lógica de Programação
* Desenvolver raciocínio lógico utilizando estrutura de decisão "Se"

---

# Fórmula Utilizada 🔢

**Consumo Médio Mensal:**

→ **Potência em Watts** * **Média de Horas por dia** * 30 / 1000

**Custo Médio Mensal:**

→ **Consumo Médio Mensal** * **Tarifa de energia por hora**

> Tarifa de energia elétrica: R$ 0,93/kWh

# Como Utilizar? 👨‍💻

**Pré-requisitos**

→ Ter o Python 3 instalado no computador.

Para verificar se o Python está instalado, execute no terminal:

```bash
python --version
```
---

**Executando o projeto**

→ Clone este repositório:

```bash
git clone https://github.com/misantos13/consumo-energia.git
```

→ Entre na pasta do projeto

→ Execute o programa `app.py`

---
# O que fazer no Programa 🤷‍♂️

→ Inicie o programa

→ Informe o **nome do aparelho** a ser analisado

→ Informe a **potência do aparelho** em Watts

→ Informe o **tempo médio de uso** em horas por dia

→ O programa fará os cálculos e informará o **consumo e o custo médios mensais**.
